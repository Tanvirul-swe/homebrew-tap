# Homebrew Tap for VetroLog

Official Homebrew tap for [VetroLog](https://vetro.hifzio.com/) — High-performance desktop SQLite database inspector for mobile developers (Flutter, Android, React Native).

## 🚀 Installation

Install VetroLog directly via Homebrew Cask:

```bash
brew install tanvirul-swe/tap/vetrolog
```

Or add the tap first and then install:

```bash
brew tap tanvirul-swe/tap
brew install --cask vetrolog
```

## 🔄 Updates

To update to the latest version of VetroLog:

```bash
brew upgrade vetrolog
```

## 🗑️ Uninstallation

```bash
brew uninstall --zap vetrolog
```
